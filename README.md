# Portfolio Website – Udeshi Irushika Shamodani (Banking Internship version)

Plain HTML, CSS and JavaScript. No frameworks, nothing to install.

## Folder structure

```
portfolio/
├── index.html                                  ← all content (edit text here)
├── css/style.css                               ← colours at the top, in :root
├── js/script.js                                ← mobile menu, active link, scroll animation
├── assets/                                     ← profile.jpg and project screenshots
└── README.md
```

## Update the existing GitHub site

1. Open your portfolio repository on GitHub.
2. Click **Add file → Upload files** and drag in **everything inside** this folder
   (`index.html`, `css`, `js`, `assets`). Same file names will be replaced.
3. Click **Commit changes** and wait a minute or two.
4. Delete the old `assets/wp-*.jpg` files from the repository (no longer used).
5. Refresh your portfolio address.

`index.html` must be at the top level of the repository, not inside another folder.
